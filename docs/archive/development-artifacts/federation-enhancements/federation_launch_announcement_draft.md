## 🚦 Getting Started

### For New Instances
```bash
# One-command deployment
curl -sSL https://get.lesser.social | bash

# or use our Terraform modules
terraform apply -var="instance_domain=you.social"
```

### For Existing Mastodon Instances
```bash
# Easy migration with data preservation
lesser-migrate --from mastodon --preserve-ids
```
