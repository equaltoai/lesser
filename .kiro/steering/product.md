# Lesser - Product Overview

Lesser is a 100% complete serverless ActivityPub implementation that makes federated social media essentially free to operate. It's built with Go, AWS Lambda, and DynamoDB, designed to be cost-effective and scalable.

## Key Features

- **Full ActivityPub Federation**: Complete implementation of the ActivityPub protocol for federation with the Fediverse
- **Mastodon API Compatibility**: 100% compatible with Mastodon clients and APIs
- **Cost-Effective**: Runs at 1/100th the cost of traditional hosting ($1-10/month for hundreds of users)
- **AI-Powered**: Semantic search, content understanding, and moderation assistance
- **Modern Authentication**: OAuth 2.0, WebAuthn/Passkeys, and Web3 wallet support
- **Serverless Architecture**: AWS Lambda functions, DynamoDB, S3, and other serverless services

## Project Status

The project has achieved complete MVP status with full ActivityPub federation and Mastodon API compatibility. It includes more features than many established ActivityPub implementations.

## Target Use Cases

- **Personal Instances**: Individual social media presence at minimal cost
- **Community Platforms**: Niche communities, professional networks, local groups
- **Business Solutions**: Customer engagement, internal communications, brand presence
- **Developer Platforms**: Building on Lesser APIs, extending functionality
